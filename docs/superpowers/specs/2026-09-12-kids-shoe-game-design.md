# くつ左右おぼえゲーム 設計書

作成日: 2026-09-12

## 目的

3歳半の双子が、靴の左右を自分で判別して履けるようになるためのゲーム。
「逆に履いたときの見た目」を繰り返し見せて、実生活で気づける力をつける。

## 前提

- 対象: 3歳半、文字は読めない
- 端末: タブレット横持ち、ブラウザで動作。ホーム画面に追加して使う
- 操作: ドラッグ＆ドロップ（タップも許容）
- 文字を一切使わない。アイコンと音で伝える

## 技術方針

- HTML + CSS + 素の JavaScript。ビルドなし、外部ライブラリなし
- 絵は手描き SVG（靴は実物写真をもとにイラスト化）
- 保存は localStorage のみ。外部送信なし
- 効果音は Web Audio API で生成（音声ファイル不要）。声は使わない

## 個人情報の扱い

- 子供の名前はコード・データに保存しない。プロファイルは `bug` / `dress` のアイコン ID のみ
- 靴の写真は SVG に描き起こした後、リポジトリには写真そのものを含めない
- 保存データは進捗数と設定値のみ。設定画面から全消去できる

## 画面構成

### 1. プロファイル選択
- 虫アイコンとドレスアイコンの2つの大きなボタン
- タップでその子のセッションが始まる
- 隅の小さな歯車を長押し（2秒）で親設定へ

### 2. ゲーム画面
- 中央にキャラクター（裸足）。足元に左右の足の置き場
- 床に靴が2つ、左右ランダムに配置
- 靴を足にドラッグして履かせる。両足履いたら判定

**正解時**
- キャラがジャンプ、キラキラ演出、上昇音
- コレクションのカウントが1増える。5個ごとに新アイテム解放演出

**不正解時**
- 履いた靴のつま先が外を向いた絵に変わる（逆履きの見た目）
- キャラが「？」の顔で足踏み。下降音
- 1秒後に靴が床に戻る。やり直し
- 3回連続で間違えたら、正しい組み合わせの靴が点滅してガイド

**判別ヒント**
- 靴の内側（土踏まず側）に半分ずつの絵。正しく並ぶと1枚の絵になる
- 実物の靴に同じシールを貼れば現実とつながる（アプリ外の運用）

### 3. コレクション画面
- 虫プロファイル: 昆虫図鑑。ドレスプロファイル: クローゼット
- 解放済みは色つき、未解放はシルエット
- 解放済みをタップすると拡大して動く（羽ばたく、くるっと回る）

### 4. 親設定（隠し）
- 1日のラウンド上限（初期値 10）。上限に達したらキャラが寝て終了
- 靴セットの選択（複数の靴を登録できる）
- データ全消去

## データ

```
localStorage["kids-shoe-game"] = {
  profiles: {
    bug:   { correct: 0, unlocked: [] },
    dress: { correct: 0, unlocked: [] }
  },
  settings: { dailyLimit: 10 },
  today: { date: "2026-09-12", rounds: 0 }
}
```

## ファイル構成

```
index.html        画面の骨組み
css/style.css     レイアウト・アニメーション
js/main.js        画面遷移・状態管理
js/game.js        ラウンド生成・ドラッグ・判定
js/collection.js  図鑑・解放ロジック
js/storage.js     localStorage の読み書き
js/audio.js       効果音
assets/shoes/     靴の SVG（左右ペア）
assets/items/     虫・ドレスの SVG
assets/chars/     キャラクターの SVG
```

## 検証方法

- タブレット実機のブラウザで、ドラッグで靴を履かせられること
- 逆に履いたときに逆履きの絵が表示され、靴が戻ること
- 5正解ごとに図鑑が増えること
- ラウンド上限で終了すること
- 判定ロジック（左右の組み合わせ・解放条件・日付リセット）は Node の単体テストで確認

## やらないこと

- ログイン、クラウド同期、複数端末の引き継ぎ
- 音声読み上げ
- 靴以外の着替え要素
